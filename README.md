# Cześć, jestem Oliwier

Studiuję Sztuczną Inteligencję w Energetyce na Politechnice Lubelskiej. Buduję projekty związane z wdrażaniem systemów IT: analiza procesów, dokumentacja wdrożeniowa, migracja i synchronizacja danych, API oraz automatyzacja w Pythonie.

Wszystkie projekty dotyczą jednego fikcyjnego wdrożenia: uczelnia przechodzi na elektroniczny obieg dokumentów, migruje dane pracowników, synchronizuje konta i obsługuje zgłoszenia użytkowników.

## Projekty

| Projekt | Opis | Technologie |
|---|---|---|
| [obieg-dokumentow-wdrozenie](https://github.com/xg0m/obieg-dokumentow-wdrozenie) | Case study wdrożenia: wymagania, proces BPMN, konfiguracja, scenariusze UAT, instrukcja i plan szkolenia | BPMN, Mermaid, Markdown |
| [migration-validator](https://github.com/xg0m/migration-validator) | Walidacja i migracja danych pracowników z CSV do SQLite z raportem w Excelu i weryfikacją SQL | Python, SQL, pytest, GitHub Actions |
| [user-sync](https://github.com/xg0m/user-sync) | Synchronizacja kont z eksportem kadrowym: plan zmian, tryb podglądu i limit bezpieczeństwa | Python, pytest, GitHub Actions |
| [helpdesk-ticket-api](https://github.com/xg0m/helpdesk-ticket-api) | REST API zgłoszeń helpdesk: obieg statusów, SLA, komentarze, klucz API | Python, FastAPI, SQLite, pytest |
