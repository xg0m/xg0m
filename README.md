# Cześć, jestem Oliwier

Buduję projekty związane z wdrażaniem systemów IT: analiza procesów, dokumentacja wdrożeniowa, migracja danych i automatyzacja w Pythonie.

## Projekty

| Projekt | Opis | Technologie |
|---|---|---|
| [obieg-dokumentow-wdrozenie](https://github.com/xg0m/obieg-dokumentow-wdrozenie) | Case study wdrożenia systemu obiegu dokumentów: wymagania, proces BPMN, konfiguracja, scenariusze UAT, instrukcja i plan szkolenia | BPMN, Mermaid, Markdown |
| [migration-validator](https://github.com/xg0m/migration-validator) | Walidacja i migracja danych pracowników z CSV do SQLite z raportem w Excelu i weryfikacją SQL | Python, SQL, pytest, GitHub Actions |

## Co pokazują moje projekty

- Analiza wymagań i dokumentacja wdrożeniowa
- Modelowanie procesów w BPMN
- Migracja i walidacja danych w Pythonie, SQL i Excelu
- Testy automatyczne i CI (pytest, GitHub Actions)
- Praca z narzędziami AI w wierszu poleceń, z regułami zapisanymi w pliku AGENTS.md
